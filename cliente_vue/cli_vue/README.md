# Painel Vue

Aplicação de estudo desenvolvida com **Vue 3** e **Vue CLI**.

## Tecnologias

- Vue 3
- Vue CLI
- Babel
- ESLint
- JavaScript

## Como executar

Instale as dependências:

```bash
npm install
```

Inicie o ambiente de desenvolvimento:

```bash
npm run dev
```

A aplicação ficará disponível no endereço informado pelo Vue CLI no terminal.

## Build de produção

Para gerar os arquivos otimizados:

```bash
npm run build
```

## Lint

Para verificar possíveis problemas no código:

```bash
npm run lint
```
